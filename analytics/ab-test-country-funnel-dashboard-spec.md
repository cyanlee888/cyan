# A/B Test 主链路国家拆分看板口径

## 目标与指标框架

本模块用于回答“同一 A/B 主链路在重点国家的到达与流失是否不同”，不单独承担实验胜负判断。

| 层级 | 指标 | 用途 |
|---|---|---|
| 北极星指标 | 7d 成熟生产支付成功率 | 实验最终商业结果；当前样本尚未成熟 |
| 输入指标 | 登录注册、首课开始 / 完成、各 Paywall 与 checkout_start 到达率 | 定位链路差异与流失位置 |
| 健康指标 | 稳定进组数、first_open 基数、事件完整性、版本可比性 | 防止小样本或漏埋点造成误判 |
| 业务指标 | 生产订单 SUCCESS 数与收入 | 与 checkout_start 分开观察 |

## 筛选与数据口径

- 时间：首次进组在 `2026-07-31 00:00 UTC` 至 `2026-08-03 04:04 UTC`；同一事件截点重跑时纳入迟到事件回补。
- 平台：Android。
- 实验：`conv_funnel_v1`，仅保留稳定 A / B 分组设备；冲突与 fallback 不进入效果漏斗。
- 国家：使用设备首次稳定 `experiment_group_assign` 事件的 `geo.country` 固定归属，不随后续访问地点变化。
- 国家 Tab：全部、韩国、沙特阿拉伯、马来西亚、印度尼西亚、越南；“全部”包含其他国家与未知地区，并非五国合计。
- 漏斗分母：每个国家、每个组别命中 `first_open` 的设备数。稳定进组但未命中 `first_open` 的设备仅显示在样本说明中。
- 漏斗规则：节点需累计命中全部前序节点，不强制按原始事件时间戳排序，以降低分组与服务端事件延迟写入的影响。
- 注册成功：`signup_result` 且成功参数为 `1 / true / success`。
- 首课：A 组体验课 Lesson ID `732 / 1615 / 734 / 733 / 1613 / 1614`；B 组新人引导课 Lesson ID `1661`。
- 支付发起：`subscription_checkout_start` 仅表示 checkout 发起，不等于生产订单支付成功。

## 展示规范

- 一个共享国家 Tab 同时更新 A / B 摘要卡、路径条、漏斗表、样本说明与断点说明。
- 每个视图先显示 A / B 稳定进组数和 `first_open` 基数，再展示逐步到达、上一步转化、启动转化与本步流失。
- 任一组 `first_open < 30` 时显示“小样本，仅观察”，不输出国家优劣结论。
- B 组 `1.4.2` 的学习计划 H5 与第一轮 Paywall 存在埋点缺口；对应节点只用于排查，不能作为国家横向比较依据。

## 监控与复盘

- 数据更新：实验观测期内按需重跑；正式长期看板建议每日 UTC 日切后更新。
- 告警：稳定分组 fallback > 1%、同设备分组冲突 > 0、关键事件连续 6 小时为 0、版本间节点到达率突降 30% 时提示数据质量异常。
- 复盘：先检查样本量和版本完整性，再比较国家漏斗；只有 7d 成熟且事件口径可比后，才讨论实验胜负或国家策略。
