留存 Retention · GA4 设备级 Cohort

采用常见的 Exact-day / 第 N 日留存：按 first_open 的 UTC 日期分 cohort，同一 GA4 设备在恰好第 N 个自然日产生明确前台活跃事件（session_start / user_engagement / screen_view / page_view）即算回访；notification_receive、app_remove、app_update 等后台或系统事件不计。它不是滚动留存，也不是账号级跨设备留存；D1 可测至 08-04、D3 至 08-02、D7 至 07-29。

变现:发起订阅 ≠ 成功付费 Monetization Reality

「发起订单」的埋点量 ≠ 真实成功付费。发起订单对应事件是 subscription_checkout_start(带 order_id,进结算即建一张 payment_order);subscription_purchase_result 无成功标识、且混入续订/恢复购买,不能当成功口径,已不采用。以生产库支付订单为准,投放期发起了大量购买,但几乎没有走完商店支付。
