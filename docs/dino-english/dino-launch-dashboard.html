Monetization: Checkout Started ≠ Payment Success Monetization Reality

Checkout-start events are not the same as successful payments. A checkout start is subscription_checkout_start with an order_id, which creates a payment_order as soon as checkout opens. subscription_purchase_result has no success flag and mixes renewals/restores, so it is no longer used as the success definition. Production payment orders are authoritative: many checkouts started during the campaign, but very few completed store payment.
