留存明细 Retention Detail

采用市面常用的 Exact-day / 第 N 日留存：以 first_open 的 UTC 日期分 cohort，同一 user_pseudo_id 在恰好第 N 个自然日产生明确前台活跃事件（session_start / user_engagement / screen_view / page_view）即算回访。它不是“第 N 日之前回来过一次”的滚动留存，也不是账号级跨设备留存。

口径判断:当前只将前台会话、前台互动、页面或屏幕浏览视为回访；notification_receive、app_remove、app_update 等后台或系统事件不计，因此比“任意事件”口径更接近用户真实打开并使用 App。若要衡量学习价值，建议并列增加“第 N 日发生学习事件”的学习留存；重装或换设备会被视为新设备，是设备级口径的固有限制。
